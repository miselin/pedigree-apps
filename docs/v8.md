# V8 embedding port

The amd64 port packages V8 13.6.233.17 as a static embedding library, public
C++ headers, pkg-config metadata, and the `v8-qualify` example. Node.js and
npm are separate follow-up ports.

## Install

```sh
pup sync
pup install v8
v8-qualify jitless
```

## Build

```sh
PEDIGREE_APPS_JOBS=4 ./buildPackages.sh --only v8
./buildPackages.sh --only v8 --audit-only
```

Use four jobs on an 8 GiB Docker builder. The recipe builds the unusually
large TurboFan CSA optimization unit separately to avoid concurrent memory
pressure, retaining `-O2`. The source and object cache survives a failed
build, so rerunning reuses completed work.

The build uses the SHA-256-pinned Node 24.20.0 source archive as a carrier for
V8 and its matching vendored dependencies. Only the selected V8 archives are
built. Linux-native generators, including Torque and `mksnapshot`, run in
the amd64 Docker builder. The Pedigree GCC toolchain compiles the target
library using V8's Linux/musl platform path and pinned Linux UAPI headers.
The compiler's C++ ABI and target libc remain the Pedigree SDK's.

The incremental source and object cache is `.build/x86_64/v8`. A changed
source pin invalidates the source cache. The clock patch is reapplied to
pristine input while preserving unchanged files and compiled objects. Host objects are
excluded from the installed archive. GYP's thin target archives are merged
into a self-contained `/usr/lib/libv8.a`; build-tree object files are not
needed by consumers. The build installs an embedded V8 startup snapshot.

## Check Abseil separately

The smaller Abseil probe exercises clock calibration, blocking and timed waits,
and contended synchronization. Build it without compiling V8 or its generators:

```sh
docker run --rm --platform linux/amd64 --user "$(id -u):$(id -g)" \
    --env HOME=/tmp --volume "$PWD:/workspace" pedigree-apps-builder:local \
    python3 /workspace/scripts/build-v8.py --abseil-only --jobs 4
python3 scripts/qualify-language-ports.py \
    --iso ../pedigree/build/pedigree.iso --disk ../pedigree/build/hdd.img \
    --suite language-ports/v8/abseil-suite.json \
    --output-dir .build/language-ports/v8/abseil-1cpu \
    --cpus 1 --memory 2048 --timeout 120
```

Repeat with a new output directory and `--cpus 4`. This tests V8's pinned
vendored Abseil, independently of the separate `abseil-cpp` package.

On 2026-09-07, this suite passed on one and four CPUs, covering CPU/cycle
frequency initialization, monotonic time, untimed notifications, timeouts and
deadlines, 8,000 mutex-protected updates, and distinct live thread IDs. The
logs and payload hashes are retained in `.build/language-ports/v8/abseil-1cpu`
and `abseil-4cpu`. Each run took approximately 32 seconds including boot.

## Embed

Use `pkg-config --cflags v8` and `pkg-config --static --libs v8` with the
target C++ compiler. The flags select C++20, disable RTTI, and match V8's
Promise embedder-field layout. An application can keep its V8 integration
in a separate translation unit when other code needs RTTI.

The example is installed at `/usr/share/doc/v8/probe.cc`. On a system with
a working native C++ compiler:

```sh
g++ $(pkg-config --cflags v8) /usr/share/doc/v8/probe.cc \
    -o v8-example $(pkg-config --static --libs v8)
./v8-example jitless
./v8-example jit
```

Native compilation is not established by cross-building this port. The
packaged example is dynamically linked to Pedigree's musl loader and
statically links V8 and the GCC C++ runtime.

## Configuration and qualification

Sparkplug and TurboFan are included. ICU/Intl, Maglev, pointer compression,
and the V8 sandbox are disabled. WebAssembly and inspector support are
compiled but remain outside the initial runtime qualification. The source
carrier's `--without-inspector` option omits Node's integration; its V8
library target still includes the inspector implementation.

Target Abseil uses its pthread condition-variable waiter. Its default Linux
waiter requires `FUTEX_WAIT_BITSET | FUTEX_CLOCK_REALTIME`, which Pedigree
does not implement. The pthread backend uses musl's supported futex path;
this private build setting does not change the public embedding API.
A small Abseil patch falls back from an unavailable `CLOCK_MONOTONIC_RAW` to
`CLOCK_MONOTONIC` for CPU-cycle calibration. Calibration and error checks
remain enabled. Its source diff and hash are included in the package.

V8 retains its normal 512 MiB x64 code reservation. Pedigree requires the
large sparse mapping fixes in `fff825465` or later for this configuration.
The test covers both a 64 MiB code reservation and the 512 MiB default, with
a 64 MiB heap limit, a 512 KiB JavaScript stack budget, and one platform
worker. It does not establish the behavior of large heaps or sustained
concurrent JIT/GC workloads.

The three test profiles cover modern JavaScript, typed buffers, C++ callbacks,
explicit Promise microtasks, caught exceptions and recovery, observed garbage
collection, and two complete isolate lifecycles. The JIT profile additionally
requires a machine-code event for its named JavaScript function. PASS is
printed only after V8 and its platform have shut down.

```sh
python3 scripts/qualify-language-ports.py \
    --iso ../pedigree/build/pedigree.iso --disk ../pedigree/build/hdd.img \
    --suite language-ports/v8/suite.json \
    --output-dir .build/language-ports/v8/qemu-1cpu \
    --cpus 1 --memory 2048 --timeout 600
```

Repeat with a new output directory and `--cpus 4`. Use freshly rebuilt guest
images matching the kernel being qualified. The runner retains image and
payload hashes, the serial console, case statuses, and the QEMU command.

On 2026-09-07, all three profiles passed in serial QEMU guests with one and
four CPUs, 2 GiB RAM, and images from Pedigree commit
`6cb21345c075b9a66eb55863b874afcbd8b0abfc`:

| Profile | Code reservation | One CPU | Four CPUs |
| --- | --- | --- | --- |
| `jitless` | 64 MiB | PASS | PASS |
| `jit` | 64 MiB | PASS | PASS |
| `jit-default` | 512 MiB | PASS | PASS |

Each profile completed two isolate lifecycles and platform shutdown. The full
suite took 96.64 seconds on one CPU and 115.91 seconds on four CPUs, including
boot. Logs are in `.build/language-ports/v8/qemu-1cpu-final` and
`qemu-4cpu-final`. The tested image, executable, library, PUP, and serial-log
hashes are recorded in
[`qualification.json`](../language-ports/v8/qualification.json).

The final PUP passes the artifact audit. Installed public headers compile
with the exported pkg-config flags, all three profiles pass the Linux
reference check using Pedigree's musl, and all 291 tests in the isolated V8 commit tree pass.
Guest tests injected the same cross-built executable carried in the audited
PUP; installing the PUP inside the guest and native compilation were not
exercised. Node.js application compatibility remains a separate milestone.

artifact audit and verified the origin catalog and archive. An independent
